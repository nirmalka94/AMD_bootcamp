# Day 8 — Interview Preparation Notes (REFERENCE)

There is no new mandatory theory today. Use these prompts to structure explanations.

## Coding interview
- Clarify input constraints and expected behaviour.
- Give a simple correct approach first.
- Explain the data structure choice.
- State time and space complexity.
- Test normal, empty, boundary, duplicate, and invalid cases.
- Keep code readable and compile incrementally.

## C++ fundamentals
Be ready to explain value versus reference, const correctness, object lifetime, RAII, smart pointers, virtual destructors, STL container trade-offs, and iterator invalidation.

## Concurrency
Be ready to explain data races, mutexes, condition variables, thread lifetime, deadlock, and why callback work should be bounded.

## Robotics systems
Describe a real system using data flow:
sensor input → preprocessing → perception/localisation → planning → control.
Discuss timing, queueing, memory ownership, failure handling, observability, and resource constraints.

## Technical communication
Distinguish what you measured from what you inferred. Explain trade-offs and failure modes. If you do not know something, state the boundary of your knowledge and how you would investigate.
