# Day 4 Cumulative Exam

**Time limit:** 50 minutes. **Total:** 30 marks.

## Part A — Coding (15 marks, 25 minutes)
Implement:
```cpp
int longest_unique_substring_length(const std::string& text);
```
Return the length of the longest substring containing no repeated characters.

Examples:
- `"abcabcbb"` → 3.
- `"bbbbb"` → 1.
- `""` → 0.

Aim for O(n) time.

## Part B — Debugging (5 marks, 10 minutes)
A sliding-window implementation adds each new value to `sum` but never subtracts the value leaving the window. Explain why the computed sum grows incorrectly and describe the required update order.
