# Day 4 — Data Structures and Algorithms for Coding Interviews

**Theme:** Solve representative problems using repeatable patterns, not memorised solutions.

## Learning outcomes
- Recognise array/string, hash-map, two-pointer, sliding-window, stack, and binary-search patterns.
- State a brute-force solution before optimising.
- Analyse time and space complexity.
- Write edge-case tests before declaring a solution complete.

## Main assignment
Complete the Sensor Event Processor. It finds a target-sum pair, computes a maximum window, and validates bracket-like message delimiters.

## Scope control
Only the patterns in CORE theory are mandatory. Do not attempt a large catalogue of unrelated problems. The goal is to learn a small set of reusable approaches and explain trade-offs.
